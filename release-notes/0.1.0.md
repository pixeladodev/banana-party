# Banana Party 0.1.0

**Banana Party** is an Apps-shelf launcher for BananaOS: a **game library** with grid or list, favorites, recents, play time, and covers. Games run on a **pinned emulator build** shipped inside the zip (not the system menu binary).

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Runs on any **BananaOS** version: it brings its own emulator and leaves the system one alone. Tested on **BananaOS 0.5.3.4** and **0.5.2.2**.

### What is in this release

- **Shelf library first:** open Apps and browse every title on the card in a sideways grid (toggle list with **X**), or jump back from **Recent**.
- **Focus card:** cover art when available, ROM banner icons in rows, cumulative play time, last played, and save size.
- **Favorites** use the same keys as the system menu where possible; **START** opens settings rows (updates, about, uninstall).
- **Sounds** on scroll and selection, held-direction repeat, and touch rails on long lists.
- **Sort A–Z** follows the same title cleanup rules as the system game list.
- **Updates** download from this repository with the careful folder swap used by other Store apps.
- **One-file installer:** `Install-Banana-Party.sh` in **`store/tiles`** once; run it from Apps to unpack into **`store/apps`** and install the shelf tile.

### Install or update

**Option A — one file (recommended)**

1. Download **`Install-Banana-Party.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` tree.
3. Reboot once, open **Apps**, and run the installer tile.

**Option B — zip**

1. Extract the zip. Copy **`banana-party`** into **`store/apps/`** and **`Banana Party.sh`** into **`store/tiles/`**. Do **not** replace the whole `store` folder.
2. Reboot once and open **Apps**.
3. Leave **Apps** and open **Apps** again so the shelf list refreshes (temporary BananaOS limitation).

### Emulator inside the zip

**Banana Party** is the Apps-shelf app (`store/apps/banana-party`). The on-screen library is built here. The **`emu/bananads`** binary and its launcher scripts are **bundled at package time** from the published **bananads-lan 0.1.0** emulator zip (checksum in `app/manifest`). That emulator source lives in a separate repository; you install **Banana Party**, not the emulator repo by itself.

### Tested on

RG DS and RG DS Plus on BananaOS 0.5.3.4: grid and list browsing, favorites toggles, one-file install, update check against this repository, and return-to-library after quitting a title.

### Known limitations

Leave **Apps** and open **Apps** again after install so BananaOS refreshes the shelf list (same workaround as other Store apps). Multiplayer uses the bundled emulator build; host and join from the in-game local play menus.

### Uninstall

Open the app, **START** for settings, **Y**, then **A** to confirm. The folder under **`store/apps/banana-party`** and the shelf tile are removed.
