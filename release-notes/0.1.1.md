# Banana Party 0.1.1

A fix release for **Banana Party 0.1.0**. The 0.1.0 zip left out the room ROM (`emu/lobby.nds`), so the app could browse the library but could not start any game. This release ships it.

**Devices:** Anbernic **RG DS** and **RG DS Plus**. Banana Party brings its own emulator and leaves the system one alone.

### What changed

- **Games start again:** the zip now carries `emu/lobby.nds`, the small room ROM the party lobby runs before and between games. Without it, picking a title did nothing.
- **Reproducible room ROM:** the package step builds `emu/lobby.nds` from source at a pinned commit and checks its SHA-256 before it goes into the zip. Packaging now stops if the ROM is missing, so a release cannot ship without it again.
- **Correct emulator version in the notes:** these notes now name the emulator release actually pinned in `app/manifest` (**bananads-lan {emulator_version}**). The 0.1.0 notes named the wrong one.

Nothing else changed: the library, favorites, recents, play time, covers, sounds, settings and the updater work as in 0.1.0.

### Install or update

**Already on 0.1.0:** open Banana Party, press **START**, and run the update row. It downloads this release from this repository and swaps the folder safely.

**Option A — one file (recommended)**

1. Download **`Install-Banana-Party.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` tree.
3. Reboot once, open **Apps**, and run the installer tile.

**Option B — zip**

1. Extract the zip. Copy **`banana-party`** into **`store/apps/`** (replacing the old `banana-party` folder) and **`Banana Party.sh`** into **`store/tiles/`**. Do **not** replace the whole `store` folder.
2. Reboot once and open **Apps**.
3. Leave **Apps** and open **Apps** again so the shelf list refreshes.

### Emulator inside the zip

The **`emu/bananads`** binary and its launcher scripts are bundled at package time from the published **bananads-lan {emulator_version}** emulator zip (checksum in `app/manifest`). The room ROM is built from source at the commit named in `app/manifest` and checked against `lobby_rom_sha`.

### Tested on

RG DS and RG DS Plus on BananaOS 0.5.3.4:

- the release zip carries `emu/lobby.nds` with the pinned checksum;
- a clean build of the room ROM gives the same bytes on two machines;
- the zip layout matches what the app expects: `emu/bananads`, `emu/lobby.nds` and the launcher scripts.

### Known limitations

Leave **Apps** and open **Apps** again after install so BananaOS refreshes the shelf list. Multiplayer uses the bundled emulator build; host and join from the in-game local play menus.

### Uninstall

Open the app, **START** for settings, **Y**, then **A** to confirm. The folder under **`store/apps/banana-party`** and the shelf tile are removed.
