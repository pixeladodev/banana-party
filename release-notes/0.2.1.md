### What changed

- **The bundled emulator is up to date** (**bananads-lan {emulator_version}**): it is built from the upstream commit that the system packages now, instead of the one from before it. Two of the changes that come with it are in this release: the in-game menu's clicks now follow the system's *Menu sounds* setting, and the microphone is turned up ten times before the noise gate, so a voice reaches the game instead of being cut off.
- **The app itself is unchanged:** the library, the Party, DS Download Play, the badges, the favorites, the ping colors and the saves shared with the system work exactly as in the previous release.

### Installation

Works on the Anbernic **RG DS** and **RG DS Plus**. If Banana Party is already installed, this replaces it and keeps your settings, favorites and play time.

1. Download **`Install-Banana-Party.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` folder.
3. Reboot once, open **Apps**, and run the installer tile.
