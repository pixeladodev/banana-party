### What changed

- **DS Download Play from the library:** press **SELECT** in the library to open the DS menu and receive a game from another console. A question comes first; **X** on it resets the DS menu settings kept on this console. This uses your own console's BIOS and firmware (`bios7.bin`, `bios9.bin`, `firmware.bin`) in the **bios** folder at the root of the card; the first launch without them says once where they go. The app does not include these files.
- **Badges on the picked game:** **Multi-card** (each console needs its own card) and **DS Download Play** (the other consoles can download it from this one). Badges are read in the background, so browsing never waits on the card.
- **Back on your game:** leaving the DS menu returns to the game that was picked when it opened.
- **Saves shared with the system:** games played in a Party now read and write the same save as when you open them from the DS menu of the console. Nothing is written beside the ROM anymore. Save states stay in the app's own folder.
- **Party:** what you host or join on your network is a **Party**, in English and in Spanish.
- **Library buttons:** **Y** opens the Party. **X** opens the picked game's options, where you add it to or remove it from your favorites.
- **Ping colors:** green up to 5 ms, amber up to 15 ms, red above, in the library and in the Party.
- **Notes before the DS menu opens:** SELECT now explains what to expect: join a Party first so another console sends the game; if you are the Party's host you can still receive one; a ping above 5 ms names the player and suggests Direct Link; with auto discovery off the DS menu won't find anyone, but you can still change your DS settings.
- **DS Download Play only joins:** in a Party with auto discovery on, the DS menu looks for the console sending the game and joins it, and never becomes the host itself.
- **Wi-Fi address per console:** the bundled emulator (**bananads-lan {emulator_version}**) gives each console its own DS Wi-Fi address from the card's machine ID, with the generated firmware and with your own, the same way as the system's DS emulator.
- **Smaller fixes:** the cover shine stays on the library's top screen, and a key release that gets lost no longer leaves the list scrolling.

### Installation

Works on the Anbernic **RG DS** and **RG DS Plus**. If Banana Party is already installed, this replaces it and keeps your settings, favorites and play time.

1. Download **`Install-Banana-Party.sh`** from this release.
2. Copy only that file into **`store/tiles`** on the shared **banana** folder. Do **not** replace the whole `store` folder.
3. Reboot once, open **Apps**, and run the installer tile.
